# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Features
- Home, About Me, Education, Technical Skills, Projects, and Contact sections
- Responsive desktop and mobile navigation
- Mobile menu toggle and copy-email interaction
- Smooth in-page navigation and reduced-motion support
- No framework or build tools required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Personalise before publishing
Search and replace the sample content in `index.html`:
- `Your Name` and `YN`
- Education details and years
- Email address, LinkedIn URL, and GitHub URL
- Project descriptions and repository links
- Experience and skills to match your actual profile

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `personal-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After deployment, copy the published website URL.
